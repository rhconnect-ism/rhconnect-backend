\# RHConnect — Backend API



Plateforme SaaS de gestion RH — ISM Dakar

Projet de fin d'études — Licences GLRS \& CDSD — 2025/2026



\## Stack technique

\- Framework : Spring Boot 3.x (Java 17)

\- Base de données : MySQL 8

\- Authentification : JWT + Spring Security

\- Build : Maven

\- Conteneurisation : Docker



\## Installation locale



\### Prérequis

\- Java 17+

\- Maven 3.8+

\- MySQL 8+



\### Lancer l'application

```bash

./mvnw spring-boot:run -Dspring-boot.run.profiles=dev

```
